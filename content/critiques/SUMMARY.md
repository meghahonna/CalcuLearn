### integ.riemann — Riemann Sums

- **pedagogy** in `deep_dives[1].body_md, Step 2`
  - The claim 'Because f is continuous on each subinterval [x_{k-1}, x_k], the Intermediate Value Theorem guarantees that f(x̄_k) is sandwiched between f(x_{k-1}) and f(x_k)' is incorrect reasoning. IVT says that f achieves every value between f(x_{k-1}) and f(x_k), but it does NOT guarantee that f at the midpoint is between f at the two endpoints. For example, f could have a local max or min between the endpoints making f(midpoint) larger or smaller than both endpoint values. The correct bounding uses the Extreme Value Theorem: on each subinterval, m_k ≤ f(c_k) ≤ M_k for any sample point c_k, so L_n ≤ M_n ≤ U_n, and since U_n - L_n → 0, the squeeze theorem applies. The current argument is logically flawed.
  - **fix:** Replace Step 2 with the correct argument: by the Extreme Value Theorem, on each subinterval m_k ≤ f(x̄_k) ≤ M_k, so L_n ≤ M_n ≤ U_n (lower/upper Darboux sums). Since U_n - L_n → 0 by uniform continuity, the Squeeze Theorem forces M_n to the same limit. Alternatively, just note that the midpoint sum is a special case of Step 3's general argument.
